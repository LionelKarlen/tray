# Tray File Format
The Tray file format is a derivative of [`kdl`](https://kdl.dev/).

# Capture
Denotes any simple capture, with an attached header. Can contain a body and be sleeping.
## Syntax
```
capture <header> {
  [sleeping <until=DateTimeString>]
  [body <content>]
}
```
